## Sobre

Projeto de estudos desenvolvido para praticar **manipulação do DOM, eventos e operações matemáticas com JavaScript**. A calculadora estima o montante de uma aplicação financeira com juros compostos, sem aportes adicionais.

## Como funciona

Informe:

1. **Capital inicial:** valor que será aplicado.
2. **Taxa de juros mensal:** percentual ao mês.
3. **Período:** quantidade de meses.

Ao clicar em **Calcular**, o resultado é apresentado em reais usando a fórmula:

~~~text
Montante = Capital inicial × (1 + taxa mensal / 100) ^ meses
~~~

## Tecnologias

**HTML · CSS · JavaScript** — cálculo realizado diretamente no navegador.

## Executar

Baixe ou clone o repositório e abra `index.html`. Não é necessário instalar dependências.

~~~text
index.html            campos e resultado
assets/css/style.css  estilos da interface
assets/js/script.js   leitura dos campos e cálculo
~~~

> Simulação educacional com taxa fixa. Não considera impostos, inflação, taxas adicionais nem validação financeira avançada.
